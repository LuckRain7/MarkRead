# MarkRead 示例文档

> 这是一篇示例。打开任意本地 `.md` 文件，MarkRead 会把原始文本换成这样的阅读视图。

## 快速开始

1. 安装扩展，并在详情里打开「允许访问文件网址」。
2. 在地址栏粘贴本地路径，回车。
3. 阅读、跳转、切换主题。

### 能力一览

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 目录导航 | ✅ 已支持 | 二、三级标题自动生成 |
| 双主题 | ✅ 已支持 | 浅色 / 纸张衬线 |
| 代码高亮 | ✅ 已支持 | 常见语言自动识别 |
| 原文切换 | ✅ 已支持 | 一键回到源码 |
